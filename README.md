# Double J Studio — Video Editor Portfolio

A sleek, responsive, and modern portfolio website built for **Double J Studio**, showcasing professional video editing, motion graphics, and visual storytelling services[cite: 3].

## 🚀 Features
* **Hero Section:** Bold typography with a striking introductory statement ("I turn raw footage into videos people want to watch")[cite: 3].
* **Filterable Portfolio Grid:** Interactive categories allowing users to filter work by Short-Form, Long-Form, YouTube, Motion Graphics, Cinematic, Ads, and Social Media[cite: 3].
* **About Section:** Professional background, roles, and quick facts[cite: 3].
* **Services & Pricing Tiers:** Clear breakdown of professional video editing packages and pricing[cite: 3].
* **Workflow Process:** Step-by-step breakdown of how projects move from raw footage to final delivery[cite: 3].
* **Before/After Slider:** Interactive comparison showcase highlighting editing enhancement[cite: 3].
* **Contact Form:** Fully styled form and direct contact links for potential clients[cite: 3].

## 🛠️ Built With
* **Semantic HTML5**[cite: 3]
* **CSS3** (Custom Properties, Flexbox, CSS Grid, and responsive media queries)[cite: 3]
* **JavaScript** (For mobile navigation, portfolio filtering, and interactive UI elements)[cite: 3]
* **Google Fonts** (Archivo and Inter)[cite: 3]
